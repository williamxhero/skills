# 精读判例与字段

`reviews.json` 是以 `capture.json` 中原样 URL 为键的对象。逐条复制 `body_sha256`，只覆盖 `pending_review`，保证审核的是同版正文。字段和类型以项目 CLI 的 `finalize()` 为准。

| 字段 | 编辑要回答的问题 |
|---|---|
| `topic`、`locator` | 哪个人要解决什么问题？原文哪一节实际支持这个切口？ |
| `study_condition` | 研究涉及谁、与谁比较、干预多久、测了什么？剂量/频次只在核实后写。 |
| `actionable_protocol` | 读者可以做出哪个具体选择或调整？明确是作者建议还是编辑推导。 |
| `action_audience` | 推荐行动时，在本版基础精读记录中写明有证据支持执行该行动的人群。编辑独立对照原文、研究条件与适用边界，不从拟做的工具反填。旧循证记录和仅背景不必补填。 |
| `scope_limit` | 哪些人群、剂量、结局或因果关系不受支持？ |
| `papers`、`evidence_origin` | 为每个核心文献保留 `trace` 实际返回的 PMID、URL、访问状态、HTTP 码、标题；分别标明直引/补查。成功取到摘要并不证明它支持这条行动。 |
| `kind`、`G`、`S`、`P` | 有人体依据且有行动才标 `human_evidence_with_action`。G 看目标与对象，S 看对应人体证据的直接性，P 看能否执行。1＝不足；2＝有界可用；3＝清楚、直接（P 为动作及多个参数）。三项各 ≥2 且合计 ≥7 才可通过。 |
| `Reach`、`reach_reason` | 1＝专门人群/器械，2＝特定常见场景，3＝普通家庭日常决策。写明场景，不拿 Reach 补证据分。 |

资料包模式只在上述门槛通过后按[资料包精读规则](pack-review.md)填工具评审；工具形态、缺口优先级和拟售定位不参与循证准入。

拒绝只需 `{"body_sha256":"与正文一致的实际指纹","reject":"该切口缺什么证据或行动"}`。未读、请求超时、限流、篇幅不足，分别保留采集器原状态，不编造精读意见。不要为了提高保留率放行材料。

**三种容易读错的数字：**

- **单位错。** 燕麦研究中的克数可能指 β-葡聚糖，不是燕麦或总纤维的克数。可以教人读标签，不能把不明含量折算成试验剂量。
- **角色错。** 「训练了 15 周」可能只是用来检验力量与肌肉体积的相关性。作者没有提出对应可执行方案时，即使数字齐全，也拒绝该切口。
- **结局错。** 同一篇含糖饮料文章可同时引用癌症风险队列与短期人体干预。后者若没测癌症结局，不能拼成因果性防癌方案；同理，不把成人结果外推到儿童增高。

若需追查这些判例的原文、PMID 与反例，从内容工作区读取 `docs/方法论/261119.3_四源循证话题采集审计.md`；该文是一次试采证据，不是以后每轮的通过率指标。
