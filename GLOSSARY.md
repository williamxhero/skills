# To-Done delivery

Canonical language for the requested delivery goal and its required work.

## Language

**final delivery target**:
The immutable Issue identity originally supplied for this request.

**CURRENT SPEC**:
The sole SPEC presently authorized to run the delivery workflow.

**prerequisite SPEC**:
A required SPEC whose delivery must precede dependent work.

**delivered prerequisite**:
A prerequisite with applicable acceptance, full delivery, complete records and verified completed CLOSED evidence.
