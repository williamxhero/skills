# 报告站点契约

每次研究都输出以下页面。除 `index.html` 外的章节可以精简，但不可省略标题、证据状态和目录导航。

| 页面 | 职责 | 必需内容 |
| --- | --- | --- |
| `index.html` | 研究结论入口 | 策略名称、状态、验证区间、净值曲线、关键收益风险指标、核心正反结论、风险提示 |
| `methodology.html` | 策略和研究方法 | 唯一规则定义、参数、训练/验证边界、指标与基准合同、未确认假设 |
| `reproduction.html` | 文章来源或输入复现 | 来源规则、原文数字对照、单信号与完整组合对照、数据使用口径、差异解释 |
| `execution.html` | 标的和交易执行 | 标的宇宙、时点、仓位、成本、滑点、成交与市场规则 |
| `robustness.html` | 可靠性 | 基线、样本外、参数面、时间分段、滚动诊断、成本/滑点/容量压力、Bootstrap |
| `diagnostics.html` | 归因与异常 | 信号/退出/时段/市场状态/特征/股票归因、回撤、集中度、leave-one-out |
| `appendix.html` | 研究口径附录 | 数据与成交口径、指标定义、少量核心结构化证据名、研究局限 |

将图表保存在报告目录的 `assets/`。图表只能来自对应 `runs/<运行标签>/apex-output/` 的结构化曲线或注明来源的原始图表；不要以装饰性图表替代实际证据。

已回测的完整研究默认至少展示 6 张决策型图表，并覆盖净值/回撤、时间收益、归因、稳健性和执行容量。表格用于保留精确证据，默认放在图表之后或可展开区域，不能成为每页的主要内容。

首页核心结论不少于 5 条，每条必须包含“证据、含义、行动、失效条件”。报告不得只复述收益数字；必须回答何时运行、何时降风险、允许什么成交质量、容量如何控制、出现什么现象需要暂停或重做研究。

为每页添加一致的页头、返回入口链接和章节导航。使用报告目录内相对链接，使整个目录可移动和离线打开。

## 内容边界

正式报告只包含会影响策略含义、收益、风险、执行或可信度的信息。以下内容不得进入网页：

- 数据修复、接口错误、失败重试和排障过程。
- Adapter preflight、月度抓取、合同检查、不可导出计数和 staging/final 过程。
- 编译/工具命令、绝对本地路径、进程状态、哈希和完整文件清单。
- 工具内部 schema、原生/外部适配争议和与策略无关的能力说明。

这些内容统一写入 `runs/<运行标签>/run_record.md`。若内部限制实质改变策略成交，只在报告中陈述最终成交假设、偏差方向和结论影响。

附录可列出 `selection.json`、`portfolio_summary.json`、`account_curve.csv` 等少量核心相对证据名，但不得变成数据管道或运维审计页面。

研究状态仅可使用：

- `已验证`：冻结规格、正式回测和最低验证设计均完成。
- `部分验证`：有正式回测，但存在列出的未完成验证或输入假设。
- `研究设计`：尚未具备可执行规格或未完成正式回测。
- `失败`：正式运行或必要数据预检失败。
