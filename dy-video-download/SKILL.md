# DY视频下载

把一次下载视为“锁定目标、复用公开播放链路、原子落盘、独立验收”的小型采集任务。只在用户明确要求下载且视频在其当前页面中可正常公开播放时执行。

## 必须遵循的边界

1. 先读取并遵循 `$crawler` 与 `$chrome:control-chrome`。通过 Codex Chrome Extension 接管当前 Microsoft Edge `Profile 1`；扩展名称中的 Chrome 不代表使用 Google Chrome。
2. 不使用 Google Chrome、独立 Playwright、裸 CDP、remote-debugging-port、自建扩展或其他 profile。扩展提供的 `tab.playwright` 可以使用。
3. 默认不读取或导出 cookies、local storage、密码、Edge profile 文件或 session store。媒体直链优先来自当前公开播放页面，下载请求默认不得附带从浏览器提取的凭据。只有用户在本轮明确授权使用当前登录态时，才可让受信下载器最小读取必要 cookies；不得打印、保存或导出明文 cookies。
4. 不绕过登录、私密、好友可见、付费、地区、年龄、DRM 或其他访问控制。若视频不能在当前页面正常播放，停止并报告。
5. 只下载用户指定的视频，不批量扩展到作者主页、相关推荐或评论区中的其他视频。保留作者、标题和视频 ID，方便归属与追溯。

## 浏览器身份门槛

Edge 界面显示名（例如“个人 2”）和底层 profile 目录不是同一概念。必要时只读检查 Edge 主进程命令行中的 `--profile-directory`；只有结果为 `Profile 1` 才继续。不要通过读取 profile 目录来判断身份。

在开始、执行计划和最终验收中明确确认：

- Codex Chrome Extension 已接管当前 Edge `Profile 1`；
- Google Chrome 未使用；
- 独立 Playwright、CDP 和自建扩展未使用。

任一门槛不满足，就停止浏览器分支。

## 下载流程

1. **锁定目标**：从 `douyin.com` allowlist 中精确选择当前目标 tab。记录规范视频 URL、视频 ID、作者、标题、页面显示时长和当前可播放状态。页面可能包含多个 `<video>`，不得默认选择第一个元素；优先用 URL 的 `modal_id`、`/video/<aweme_id>` 或播放器容器 `data-e2e-vid` 锁定同一 ID 的视频，再用可见主播放器、作者、标题、时长交叉确认。
2. **确认输出**：解析用户指定目录的绝对路径并创建目录。文件名采用 `作者_标题_视频ID.mp4`，清理 Windows 非法字符并控制长度。已有同名正式文件时先校验并复用，或生成不冲突文件名；未经允许不得覆盖。
3. **优先官方路径**：若页面提供可用的官方“下载视频”，可先使用。按钮提示“不支持下载”、调用没有生成文件，或返回值不明确，都不算成功，必须检查本地文件。浏览器媒体下载工具显示“请求完成”也不能替代落盘检查。
4. **提取公开媒体源**：官方路径不可用但视频可公开播放时，从已锁定 ID 的主播放器读取 `currentSrc`、`src` 和子 `<source src>`。忽略 `blob:`；优先尝试页面已经提供的 `https:` 媒体 URL。若目标来自 `user/self?...modal_id=<id>` 弹窗且只暴露 `blob:`，先在当前 Edge 登录态下打开规范页 `https://www.douyin.com/video/<id>`，等待详情页重新加载后再次读取同一目标播放器；该路径可能恢复 `https:` 媒体源。只有规范页刷新后仍无 `https:` 候选，且扩展资源清单没有观测到目标视频资源（例如 `pageAssets` 中 `video=0`），才按停止条件处理。需要代码和元素选择细节时读取 [references/douyin-download.md](references/douyin-download.md)。
5. **原子下载**：在主机侧对签名媒体 URL 发起普通 GET，只携带常规 `User-Agent`、当前视频页 `Referer` 和 `Accept`；除非用户明确授权，否则不携带 cookies。流式写入本任务唯一的 `.part-<uuid>`，收到完整响应后再原子改名为 `.mp4`。不要在日志或最终答复中输出完整签名 URL。
6. **有界恢复**：403/404 通常表示签名地址过期；回到当前页面重新读取媒体源后再试。429、5xx 或瞬时网络错误可做少量退避重试。不要无限重试，也不要转向来历不明的第三方解析站。
7. **独立验收**：使用 `ffprobe` 检查容器可读、至少存在视频流、预期有声视频存在音频流、尺寸合理、文件大小大于零，并将文件时长与页面时长比较。误差超过 2 秒或 1%（取较大者）、解析失败或缺流时，保留证据并判为失败，不把 `.part` 改成正式文件。
8. **完成报告**：给出可点击的绝对文件路径、视频 ID、作者、标题、字节数、时长、分辨率和音视频编码；同时重申三项浏览器身份门槛。只报告实际验证过的项目。

## 停止条件

遇到以下任一情况时停止，不尝试规避：目标并非当前用户指定视频；页面不可播放；主页弹窗和规范视频页刷新后都只剩 `blob:` 且没有公开媒体源；扩展媒体下载方法没有产生本地文件；`pageAssets` 没有观测到目标视频资源；下载器提示需要 fresh cookies 但用户未明确授权；已授权情况下 cookie 数据库仍因权限/锁定不可读且规范页也无 `https:` 源；媒体受 DRM 或加密访问控制保护；无法区分多个播放器；输出目录不明确或会覆盖现有文件；下载后无法通过 `ffprobe` 验收。

官方路径失败、媒体源选择、流式下载范式、校验命令及本次实战故障矩阵见 [references/douyin-download.md](references/douyin-download.md)。只有进入下载实现或排障阶段时才读取该文件。
