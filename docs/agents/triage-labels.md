# Triage labels

Use the canonical role strings: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`.

`to-spec` publishes a complete SPEC with `ready-for-agent`. Missing labels are created in the user-owned `williamxhero/skills` repository only. Label presence does not imply the SPEC has been implemented or that draft source has been deployed.
