# ChatGPT 对话提取参考

仅在执行 DOM 提取、Markdown 转换或排障时读取。

## 目标容器与轮次

1. 从最新 `domSnapshot()` 确认 `main`、页面聊天标题和角色提示（常见为 `You said:` / `ChatGPT said:`）。
2. 在 `main` 内优先使用页面实际暴露的稳定角色属性（例如 `data-message-author-role`）；属性不存在时，以快照中的角色标题为锚点，向上选择最小且彼此不重叠的消息容器。
3. 用户消息正文通常是预格式化文本容器；助手正文通常是 `.markdown` 容器。选择器必须来自本页观察结果，不把这些常见形态当作无需验证的固定契约。
4. 过滤 `button`、`textarea`、输入区、响应操作组和侧边栏。正文中的普通 `a`、`table`、`pre`、`code` 应保留。
5. 对每个候选容器记录角色、正文字符数和首尾短摘要。正文为空、两个容器包含关系重叠或顺序与快照冲突时停止转换并重新定位。

## 标题

- 首选与当前 URL 精确对应的当前会话链接文字或聊天页顶部会话标题。
- `document.title` 可能是 `<项目名> - <聊天标题>`，只能在页面状态证实右侧确为当前会话名时去掉项目前缀。
- 派生 Windows 文件名时替换 `< > : " / \\ | ? *`，去掉结尾空格和句点，并拒绝空标题。用户显式给出的合法 `.md` 文件名保持不变。

## Markdown 转换

在页面作用域内递归序列化已锁定的消息正文：

| HTML | Markdown |
|---|---|
| `p` | 段落，块间空一行 |
| `h1`–`h6` | 原级别增加两级，最高不超过六级 |
| `strong` / `b` | `**text**` |
| `em` / `i` | `*text*` |
| `code`（非 `pre` 内） | 行内代码 |
| `pre` | 围栏代码块；保留语言标记（若可见） |
| `ul` / `ol` | 保留嵌套层级的列表 |
| `table` | GFM 表格；单元格内 `|` 转义，换行改为 `<br>` |
| `a[href]` | `[label](href)`；过滤 `javascript:` |
| `br` | 换行 |

合并连续空白时保护代码块和预格式化用户文本。避免对整个 `body` 使用 `innerText`；侧边栏标题、历史聊天和按钮会污染结果。

当 Node REPL 外层代码使用模板字符串承载页面脚本时，Markdown 围栏的反引号可能提前终止外层字符串。优先把可执行函数直接传给 `evaluate`；否则在页面函数内用 `String.fromCharCode(96)` 生成反引号。

## 症状驱动 fallback

| 症状 | 处理 |
|---|---|
| Edge 首次连接超时 | 按 `chrome:control-chrome` 的 Chromium 排障文档执行轻量调用并只重试一次；成功后复用同一 `edge` 绑定。 |
| `domSnapshot()` 只有当前末轮 | 向上滚动聊天区域，观察最早轮次和数量变化；达到 Skill 上限仍不完整则停止。 |
| 角色属性缺失 | 使用快照中可见的角色标题作为锚点，选择最小非重叠祖先；不得退化为整页文本转储。 |
| 标题带项目名前缀 | 与当前 URL 对应的侧边栏会话名或页头标题交叉核对后再裁剪。 |
| 文件名包含半角冒号 | 仅在派生文件名中替换为全角冒号 `：`。 |
| 写入后文件非空但内容缺轮次 | 以提取前基线为准重做；非空文件不构成成功。 |
| PowerShell 预览出现乱码 | 用 `py -X utf8` 验证实际字节与 UTF-8 解码，不依据终端默认代码页的显示判定文件损坏。 |
