## Parent

Part of #54 (SPEC P1-6: 真正实现阶段最小上下文与新鲜度保护)

## What to build

提供按 phase 和当前实体生成的最小上下文投影，保留当前实体、读取时 business version、直接依赖接口、适用决策和证据摘要；关闭的 SPEC 只返回交付摘要及可追溯的稳定指针，并提供按指针读取历史详情的接口。

## Acceptance criteria

- 每个支持的 phase 有明确投影形状，输出不再重复完整 snapshot 和顶层展开字段。
- active 与 closed SPEC 的投影分别满足最小字段和历史可追溯要求。
- 投影携带 run_id、current entity id 和 read business version。
- 缺失实体、未知 phase、损坏指针均 fail closed，不返回猜测性上下文。

## Blocked by

None (can start immediately)
