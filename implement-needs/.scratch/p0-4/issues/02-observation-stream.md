# P0-4.2: 分离业务事件与观测游标

## Parent

SPEC P0-4: https://github.com/williamxhero/skills/issues/44

## What to build

将运行时指标和外部 observation 写入独立的观测流与游标；观测只能用于诊断，不能推进业务版本、生成业务事件或满足交付完成条件。交付证明和依赖豁免等决策相关变更仍必须进入业务事件流。

## Acceptance criteria

- [ ] 观测写入不会改变业务版本、业务事件数量或任何完成判断所需状态。
- [ ] 业务证明/豁免类变更进入业务事件并推进业务版本，且与观测记录可独立查询。
- [ ] 观测冒充交付证据、交付证据冒充指标的测试均被拒绝或无法推进错误的游标。
