## Parent

Part of #46 (SPEC P1-2: 贯通 Intent、Action、回执与恢复生命周期)

## What to build

补齐 Operation Intent/Action 的正常成功、失败、未知结果状态转移，并让业务 receipt 通过统一投影更新对应 Action。

## Acceptance criteria

- 正常 response + authoritative readback 才能从 executing 转 succeeded。
- failed、outcome_unknown、paused/recovery-required 有明确状态和结构化原因。
- receipt 必须绑定 run、action、target、业务版本和幂等身份；普通 observation 不能完成 Action。
- 未知结果在对账前不得重发外部动作。

## Blocked by

- None (can start immediately)
